                Stage 01 • Ingestion Pipeline
                5 Curated Documents
              

              

                📚 Knowledge Ingestion (5 Authoritative Medical Guidelines)
              

              

                In clinical applications, general web scraping produces toxic hallucinations. ClearCare restricts its knowledge base to 
                authoritative guidelines published by the American College of Cardiology (ACC), American Heart Association (AHA), 
                American Association for Clinical Chemistry (AACC), and NIH MedlinePlus.
              

              

                

                  1. Comprehensive Metabolic Panel
                  BUN, Creatinine, eGFR, ALT, AST, Bilirubin, Electrolytes
                

                

                  2. Complete Blood Count (CBC)
                  WBC, RBC, Hemoglobin, Hematocrit, Platelets, Infection flags
                

                

                  3. Lipid Cholesterol Panel
                  Total Cholesterol, LDL-C targets (<100, <70), HDL, Triglycerides
                

                

                  4. Thyroid TSH Panel
                  TSH (0.4-4.0), Free T4, Hypo/Hyperthyroidism distinctions
                

                

                  5. Post-PCI Cardiac Stent Discharge Care
                  Mandatory Dual Antiplatelet Therapy (Aspirin + Plavix), groin puncture monitoring, red flag chest pain warnings
                

              

            


            
            

              

                Stage 02 • Preprocessing
                700 chars / 120 overlap
              

              

                ✂️ Heading-Aware Chunking (Preserving Hierarchical Context)
              

              

                Naive character splitters sever sentences and orphan medical qualifications (e.g., losing *"However, in pregnant patients..."*). 
                ClearCare implements a heading-aware sliding window chunker that prepends the active section heading 
                (# [Document > Section]) to every generated chunk.
              

              

                
# Heading-Aware Structure Injected into Every Chunk:

                
# Document: metabolic_panel_cmp.md > Section: Kidney Function & Filtration

                
Serum Creatinine reference interval: 0.6 - 1.3 mg/dL. Elevated creatinine indicates impaired glomerular filtration, but transient elevations can occur with dehydration, high-protein intake, or intense resistance exercise...

              

              

                Why 700 chars? Matches the natural size of a single medical assay. Avoids "needle-in-a-haystack" dilution while keeping full normal ranges and benign causes intact.
              

            


            
            

              

                Stage 03 • Semantic Vector Space
                384 Dimensions • ~14ms CPU
              

              

                🧠 Local Dense Embeddings (all-MiniLM-L6-v2)
              

              

                Maps text chunks into 384-dimensional dense vectors where semantically synonymous medical phrases reside close together.
                Runs 100% locally on CPU — ensuring zero Protected Health Information (PHI) leaves the user's infrastructure.
              

              

                

                  Patient Colloquialism
                  "My blood sugar was high"
                

                

                   Cosine Similarity > 85%
                  Dense Vector Proximity
                

                

                  Clinical Guideline Anchor
                  "Elevated Fasting Plasma Glucose / Hyperglycemia"
                

              

            


            
            

              

                Stage 04 • Vector Storage
                ChromaDB + HNSW Graph
              

              

                🗄️ Persistent Vector Storage (ChromaDB + HNSW Indexing)
              

              

                Embeddings are persisted to disk using ChromaDB with a Hierarchical Navigable Small World (HNSW) graph index. 
                Provides logarithmic O(log N) search complexity, enabling cold-start sub-millisecond retrieval without re-indexing.
              

              

                 Disk Persisted (`chroma_db/`)
                 Cosine Distance Space
                 Rich Metadata Anchors
              

            


            
            

              

                Stage 05 • Clinical Retrieval Strategy
                Solving "Vector Blur"
              

              

                🔎 Clinical Entity Scanning & Multi-Query Expansion
              

              

                The Multi-Analyte Vector Blur Problem: When a user uploads a 15-test metabolic panel, a naive RAG system 
                generates a single vector that is an average centroid of all tests. This diluted vector retrieves vague lab overviews, 
                missing specific guideline rules for an elevated ALT or LDL.
              

              

                

                   Naive Single-Pass RAG (Vector Blur)
                  

                    Encodes entire 15-analyte document as 1 vector → Vector gets diluted → Retrieves general introductory paragraphs → Fails to retrieve specific liver or kidney thresholds.
                  

                

                

                   ClearCare Multi-Query Strategy
                  

                    Scans 30+ clinical regex biomarkers (Glucose, ALT, LDL, eGFR...) → Issues targeted sub-queries for each analyte → Merges and deduplicates candidate guidelines.
                  

                

              

            


            
            

              

                Stage 06 • Hallucination Firewall
                Score ≥ 0.35 Filter
              

              

                🎯 Similarity Thresholding & Context Formatting
              

              

                In clinical medicine, passing an irrelevant chunk to an LLM is dangerous because it prompts speculative reasoning. 
                ClearCare strictly filters candidate chunks using a ≥ 0.35 cosine similarity threshold.
              

              

                
// Standardized Context Assembly Passed to LLM:

                
[Source 1: lipid_cholesterol_panel.md | Section: LDL-C Targets | Match: 88%]

                
Optimal LDL for high-risk CAD/stent patients is < 70 mg/dL...

              

            


            
            

              

                Stage 07 • Guardrailed Generation
                Groq LPUs • Llama 3.3 70B • t=0.2
              

              

                ⚡ Guardrailed Generation (Groq LPUs + Llama 3.3 70B)
              

              

                Inference runs on Groq Language Processing Units (LPUs) at ~500 tokens/second with a deterministic temperature of 0.2. 
                Strict system-prompt guardrails eliminate hallucination and protect patient safety:
              

              

                

                  1. Absolute Diagnosis Prohibition
                  Cannot state "You have chronic kidney disease"; must state "Creatinine is above reference interval; warrants doctor follow-up".
                

                

                  2. Mandatory Benign Causes
                  Must explain hydration, exercise, and diet causes first to prevent unnecessary patient panic.
                

                

                  3. Strict Citation Attribution
                  Every statement must explicitly reference [Source X] from the retrieved guideline chunks.
                

                

                  4. Medication Safety Lock
                  Strictly prohibited from suggesting stopping prescribed therapies (e.g., Plavix / Aspirin DAPT).
